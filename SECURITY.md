# Security Policy

## Supported Versions

Only the latest release of ANAHAD receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The ANAHAD team takes security seriously. If you discover a security vulnerability or privacy flaw in ANAHAD, please disclose it responsibly.

### How to Report
Please report security vulnerabilities by emailing the maintainer:
- **Email**: `[security@anahad.app or maintainer@example.com]`
- **Subject Line**: `[SECURITY VULNERABILITY] ANAHAD - <Short Description>`

Please include:
1. Detailed description of the vulnerability and its impact.
2. Steps to reproduce or proof-of-concept code.
3. Affected versions and Android OS environments.
4. Any proposed remediations.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide regular status updates regarding verification and patching.
- We ask that you maintain responsible disclosure and refrain from publicly disclosing the issue until a patch has been published.
